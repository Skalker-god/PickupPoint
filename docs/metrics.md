# Метрики успадкованого модуля

Модуль: `src/Legacy/` (до рефакторингу — один файл `LegacyPickupProcessor.cs`,
коміт `bf05379`; після — 10 файлів, коміт `5783bd4`).
Спосіб вимірювання: вручну за правилом курсу; LOC додатково перевірено
скриптом, який рахує непорожні рядки без рядків-коментарів, а глибину
вкладеності — за максимальною кількістю одночасно відкритих блоків у методі
без урахування дужок самого тіла.
